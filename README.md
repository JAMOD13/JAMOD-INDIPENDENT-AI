# 🚀 JAMOD-INDIPENDENT-AI
Ek powerful aur fully independent AI setup jo tumhare phone (Termux) par chalta hai. Ismein koi filtering ya restriction nahi hai.

## 🛠 Features
- **Fully Local:** Sab kuch tumhare phone par chalta hai.
- **Vision Support:** Text ke saath-saath images ko bhi analyze kar sakta hai.
- **One-Click Startup:** Bas ek command se poora system ready.
- **No Rules:** Koi external censorship ya limits nahi.

## 📥 Kaise Install Karein?
Termux open karo aur ye commands chalao:

```bash
pkg update && pkg upgrade -y
pkg install git ollama -y
git clone [https://github.com/JAMOD13/JAMOD-INDIPENDENT-AI.git](https://github.com/JAMOD13/JAMOD-INDIPENDENT-AI.git)
cd JAMOD-INDIPENDENT-AI
chmod +x start.sh
./start.sh
