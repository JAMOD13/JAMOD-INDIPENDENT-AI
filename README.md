# 🚀 JAMOD-INDIPENDENT-AI
Ek powerful aur fully independent AI setup jo tumhare phone (Termux) par chalta hai. 

## 🛠 Features
- **Fully Local:** Sab kuch tumhare phone par chalta hai.
- **Vision Support:** Image aur Text dono samajh sakta hai.
- **One-Click Setup:** Bas ek command se sab kuch ready.

## 📥 Install kaise karein?
Termux open karo aur niche di gayi commands copy-paste karo:

```bash
pkg update && pkg upgrade -y
pkg install git ollama -y
git clone [https://github.com/JAMOD13/JAMOD-INDIPENDENT-AI.git](https://github.com/JAMOD13/JAMOD-INDIPENDENT-AI.git)
cd JAMOD-INDIPENDENT-AI
chmod +x start.sh
./start.sh
